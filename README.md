# 🎖️ GED-MINDEF : Gestion Électronique des Documents
Système professionnel de gestion d'archives militaires développé avec **Django**.

## 🚀 Fonctionnalités
- Authentification sécurisée.
- Monitoring du stockage en temps réel (0.96 Mo actuellement).
- Classification "Secret Défense".
- Lanceur automatisé pour Chrome.

## 🛠️ Installation
1. Cloner le dépôt : `git clone https://github.com/votre-nom/GED-MINDEF.git`
2. Créer l'environnement : `python -m venv venv`
3. Lancer via le fichier `Lancer_GED.bat`.
